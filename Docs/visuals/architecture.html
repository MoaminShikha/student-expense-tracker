Free Money

opening_balance + total_income − committed_charges − total_spent. Committed charges deduct immediately on logging — before they're due.

Fuzzy Charges

Upcoming payments with uncertain amounts or dates. Stay PENDING until the student explicitly resolves (→ concrete charge) or discards them.

Recurring Charges

Monthly obligations (rent, phone). When marked paid, the next month's charge is auto-generated. Month-boundary safe (day 31 → last valid day).

On-Track State

GREEN → spent < 100% of budget. YELLOW → 100–130%. RED → >130%. TIGHT_MONTH → income − committed ≤ 0.

Balance State

NORMAL → free_money > caution threshold. CAUTION → above zero but tight. CRISIS → free_money ≤ 0.

Decimal Arithmetic

All monetary values use Python's decimal.Decimal. No floating-point rounding errors anywhere in the money path.

Repository Pattern

Services depend on Python Protocol interfaces, not concrete classes. Swap in-memory → JSON → Postgres without touching service code.

Immutable Models

All domain entities are @dataclass(frozen=True). Updates create new instances. Prevents accidental mutation of financial records.
