# Required Fonts

Download the static (not variable) TTF files from Google Fonts and place them in this directory.

## Playfair Display
https://fonts.google.com/specimen/Playfair+Display
Download → select "Static" → grab:
  PlayfairDisplay-Black.ttf       (weight 900 — hero number ₪640)
  PlayfairDisplay-Bold.ttf        (weight 700 — stat numbers, panel headers)
  PlayfairDisplay-Italic.ttf      (weight 400 italic — ₪ symbol)

## DM Mono
https://fonts.google.com/specimen/DM+Mono
Download → grab:
  DMMono-Regular.ttf              (weight 400 — body text, labels)
  DMMono-Medium.ttf               (weight 500 — active nav labels)

## Noto Naskh Arabic
https://fonts.google.com/noto/specimen/Noto+Naskh+Arabic
Download → grab:
  NotoNaskhArabic-Bold.ttf        (weight 700 — ميزان wordmark)

## After downloading
Place all six .ttf files directly in this directory (no subdirectories).
styles/fonts.py will load them automatically on app startup.
